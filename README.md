# UI Design Composer Demo

An interactive UI/UX visual-direction composer prototype. It combines visual templates, UX patterns, typography, layout controls and generated HTML delivery.

## Local development

```bash
npm install
npm run dev -- --port 3001
```

Copy `.env.example` to `.env.local` and provide `OPENAI_API_KEY` to enable AI generation. Environment files are excluded from Git.

## Checks

```bash
npm run audit:options
npm run build
```
